# Power BI

This directory is intended for public-safe Power BI documentation and screenshots.

Recommended contents:

```text
dashboard_overview.png
economic_overview.png
pix_analysis.png
pix_vs_gdp.png
```

The `.pbix` file is excluded by default from this documentation package.

The report should consume the Snowflake `GOLD` schema using Import mode.

See:

- `../docs/power_bi.md`
- `../docs/data_model.md`
